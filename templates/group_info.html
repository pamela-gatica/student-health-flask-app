About This Project

From a course assignment to a full portfolio project.

How It Started

This project began as a group assignment for a Python course in my Data Analytics for Business program. The original requirement was simple: store a small dataset in a SQLite database and serve it through a basic Flask website with an About page and a Data page showing a sample of the records.

How It Evolved

After the course ended, I continued developing the project on my own to turn it into a complete portfolio piece, expanding it well beyond the original scope by:

Loading the full 1,000-row dataset instead of just a sample
Adding pagination and multi-field filters (gender, activity, sleep, mood, risk) to the data table
Building an interactive Plotly dashboard with 8 charts analyzing health risk by gender, age, sleep, activity, mood, and stress
Adding a dedicated Insights page with data-driven findings, recommendations, and study limitations
Redesigning the homepage, navigation, and overall visual styling
